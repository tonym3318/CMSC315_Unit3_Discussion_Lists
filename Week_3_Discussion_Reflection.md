# Reflection Essay for Week 3 Discussion

For week 3, this assignment helped me to gain a better understanding of how Python lists handle insertion, deletion, and searching. I used a real-world broadband network example involving MPEG video channels, (same as my last week’s topic), on VLAN 200.

One challenge that I encountered was understanding how lists indexes change after inserting or deleting elements. When running my code, I made an error and accidentally removed Fox Sports 1 instead of NFL Network by indexing position 2 instead of index 1. This caused my search to return a -1. Once I modified the index position, my code ran successfully.

In the real world, list operations have impact on performance because inserting and deleting elements near the beginning or middle requires shifting of the other elements in the list. Searching can take longer as you list size increases.
